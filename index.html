Voice2Txt

Windows 语音转文字小工具 —— 按住热键说话，松开后文字自动插入光标处。
轻量单文件 · 原生 ARM64 · 小米 MiMo-V2.5-ASR 识别

⬇ 下载 Voice2Txt-win-arm64 源码

功能特性

🎙 按住说话

全局热键（默认 Ctrl+Alt，支持录制绑定 Fn 等非常规键）按住录音、松开识别，点按不误触。

⚡ 准实时上屏

停顿即切段流水识别，说一两句停一下，文字逐段跳进面板，不必等松开。

📌 自动插入

识别完成自动写入剪贴板并 Ctrl+V 到前台窗口；面板自动呼出、自动消失。

🧠 MiMo 识别

小米 MiMo-V2.5-ASR，中文/方言/中英混说/歌声均擅长，原生标点。官方订阅与 Token Plan 双支持，按 Key 自动识别。

🗂 本地历史

识别记录只存本机 %APPDATA%，双击即复制；API Key 仅存环境变量/本地配置。

🪶 轻量原生

单文件约 300KB，win-arm64 原生构建，托盘常驻，开机自启可选。

快速开始

1. 下载解压从 Releases 下载 Voice2Txt-win-arm64-v*.zip（另有 win-x64），解压得到 Voice2Txt.exe（单文件，图标已内置）
2. 配置 Key首次运行弹出设置，粘贴 API Key（Token Plan 为 tp- 开头，官方订阅同理可用），自动识别订阅类型；或设环境变量 MIMO_API_KEY
3. 说话光标点进任意输入框 → 按住 Ctrl+Alt 说话 → 松开，文字自动插入
热键设置里可改（Fn / Alt+F2 / VK:500…），支持「录制热键」实测绑定
开机自启设置 → 开机自启动（写入 HKCU Run 键）

从源码构建

# 需要 .NET SDK 8（arm64）
.\build.ps1            # 产出 bin\Voice2Txt.exe（win-arm64 单文件）
.\build.ps1 -InstallSdk # 没装 SDK 时先装
.\run.ps1              # 不构建直接跑（PowerShell 7）

隐私与安全

🔒 API Key 只存在你的电脑上（环境变量或 %APPDATA%\Voice2Txt\config.txt），不进源码、不进构建产物、不进仓库。 语音仅在识别时发送给小米开放平台接口，历史记录纯本地保存。
